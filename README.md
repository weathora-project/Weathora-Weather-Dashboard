# Weathora – Weather Dashboard with API

## Project Overview
Weathora is a web-based weather dashboard that allows users to check the current weather of any city.

## Features
- Search weather by city name.
- Display temperature, humidity, wind speed and feels-like temperature.
- Store city search history in MongoDB.
- View previous searches on the History page.
- User-friendly interface with Home, Weather, History and About pages.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Weather API:** OpenWeather API
- **Database:** MongoDB

## Requirements
- Python
- Flask
- Requests
- PyMongo
- python-dotenv
- OpenWeather API key
- MongoDB

## Installation and Setup
1. Clone or download this repository.
2. Install the required packages using:
        pip install -r requirements.txt

3. Create a .env file and configure your OpenWeather API key and MongoDB connection settings.
4. Start the Flask application using:
    python app.py

5. Open the local URL shown in the terminal in your browser.

## Security Note
Do not upload your .env file or expose your API keys and secrets publicly.
